### What's New in v0.6.0:
- **Real-Time PC Audio Streaming (WASAPI Loopback Capture)**:
  - Windows host captures all system output audio (YouTube, Spotify, games, system alerts) via native Windows WASAPI loopback (`AUDCLNT_STREAMFLAGS_LOOPBACK`).
  - High fidelity 48,000 Hz stereo audio converted to 16-bit PCM S16LE.
  - Binary `VAUD` packet framing with demultiplexing against JPEG video frames over a single multiplexed WebSocket session.
- **Android Native Low-Latency AudioTrack Playback**:
  - Direct integration into Android OS `android.media.AudioTrack` in `MODE_STREAM` via Kotlin Platform Channel with zero third-party dependencies or bloatware.
  - Keeps Android split APK lightweight (~22MB for `arm64-v8a`).
- **Interactive Audio Controls in Mobile Dock**:
  - New volume/mute toggle icon in the floating dock bar with dynamic iconography (`volume_up` vs `volume_off`).
  - Toast feedback for audio mute and unmute actions.
- **Complete Test Coverage & E2E Verification**:
  - 25 Rust unit/integration tests passing cleanly.
  - 27 Flutter widget/unit tests passing cleanly with 0 analyzer issues.
  - Live E2E streaming verified over 800+ frames on physical-equivalent emulator.
